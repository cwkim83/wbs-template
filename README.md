# WBS 일정표 템플릿 (wbs-template)

서버도, 가입도, 설치도 없이 **`index.html` 파일 하나**로 쓰는 WBS(작업 분해 구조) + 간트 일정표입니다.
브라우저에서 열면 바로 쓰고, 고치고 싶은 곳은 [Claude Code](https://claude.com/claude-code)에게 말로 시키면 됩니다.

- 대단락 → 중단락 → 소단락 …  계층 구조 (순서·들여쓰기·코드 번호 자동 부여, 위/아래 이동, 복사, 삭제)
- 간트 막대 + 오늘 선, 진도율 자동 집계(하위 행의 평균이 상위 행으로 올라감)
- 계획 대비 늦음(빨강) ↔ 정상(초록) ↔ 앞섬(파랑) 색 표시
- EVMS 요약(계획 PV · 실행 EV · SV · SPI, S-커브), 계약금액(BAC) 입력 시 금액 환산
- 간트 막대 메모 말풍선 (막대 클릭 = 보기/닫기, 우클릭 = 작성)
- PDF(A3 가로) · Excel 내보내기, 개정 번호(Rev) 자동 증가
- 데이터는 서버로 가지 않습니다.

## 30초 시작

1. 이 저장소를 내려받습니다 (GitHub 의 **Code → Download ZIP**, 압축을 풉니다).
2. **`index.html` 을 더블클릭**합니다 (Chrome · Edge 권장).
3. 비어 있는 「새 프로젝트」가 열립니다. **`+ 추가`** 로 대단락부터 넣어 보세요.
   먼저 구경하고 싶으면 상단의 **`🧪 예시 넣기`** (가상의 「사무실 이전 프로젝트」)를 누르세요.
   `index.html?sample=1` 로 열면 예시를 보기만 하고 아무것도 저장하지 않습니다.
4. 프로젝트 이름·번호·발주처·담당자는 **`✏ 프로젝트 정보`** 에서 바꿉니다.

## 데이터는 어디에 있나 — 반드시 읽어 주세요

입력한 내용은 **이 브라우저의 localStorage** 에만 저장됩니다 (자동 저장, 키 이름 `wbs_template_v1`).

- 같은 PC·같은 브라우저에서 다시 열면 그대로 보입니다.
- **다른 PC, 다른 브라우저, 시크릿 창, 브라우저 데이터 삭제 후에는 보이지 않습니다.**
- 그래서 백업과 PC 간 이동은 **`📥 JSON 내보내기`** / **`📤 JSON 불러오기`** 로 합니다.
  내보내기 파일명은 `WBS_<프로젝트명>_<날짜>.json` 이고, 불러오면 현재 데이터가 파일 내용으로 **교체**됩니다.
- 중요한 일정은 가끔 JSON 으로 내보내 두세요.
- 같은 브라우저에서 `index.html` 사본을 여러 개 열면 같은 저장소를 함께 씁니다. 같은 파일을 탭 두 개로 동시에 편집하면 나중에 저장한 쪽이 이깁니다.
- PDF·Excel 만들기는 처음 한 번 인터넷에서 라이브러리(html2canvas · jsPDF · SheetJS · JSZip)를 받아 옵니다. 오프라인이면 나머지 기능은 되고 이 둘만 안 됩니다.

## 말로 고쳐 쓰기 (Claude Code)

이 폴더에서 Claude Code 를 열고 하고 싶은 일을 그대로 말하면 됩니다. 파일이 `index.html` 하나라 고칠 곳을 찾기 쉽습니다.

- 「상태에 '보류'를 추가해 줘. 회색 배지로, 필터에도 나오게.」
- 「간트 막대 색을 담당자별로 다르게 칠해 줘.」
- 「표에 '우선순위' 칸(높음/보통/낮음)을 추가하고, 추가·수정 창에서도 입력할 수 있게 해 줘.」
- 「PDF 머리에 우리 회사 이름과 로고(`logo.png`)를 넣고, 하단 NOTE 기본 문구를 우리 문구로 바꿔 줘.」

고친 뒤에는 `index.html?sample=1` 로 열어 확인하면 저장된 데이터를 건드리지 않아 안전합니다.
